## Global Constraints

- Die ersten 12 Query-Keys bleiben exakt: `scene,preset,speed,audio,bloom,trails,scan,crt,matrix,terminal,radar,crosshair` — Reihenfolge und `on`/`off`-Encoding unverändert.
- Registry-Pfad `HKCU\Software\KuroScreensaver` unverändert; neue Werte additiv, PascalCase.
- Numerische Werte laufen als ROHE validierte Strings durch Registry+Query (nie reformatieren → Byte-Parität trivial). Validierung: Regex `^[0-9]+(\.[0-9]+)?$` + Range-Check; Save-Reject ist all-or-nothing wie bisher.
- `npm run typecheck` und `npm test` müssen nach jedem Web-Task grün sein.
- C++-Tasks: lokal nur schreiben + committen; Kompilier-/Test-Verifikation gesammelt über CI (Task 12).
- Conventional Commits mit `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- macOS-Native-Code (`native/macos/`) wird NICHT angefasst.

### Weitere Registry-Werte (nicht im Query an screensaver.html)

- `MonitorMode` = `per` (Default) | `span` — Saver.
- `WallpaperMonitorMode` = `per` (Default) | `span` — Wallpaper.
- `WallpaperScale` = num 0.25..1, Default `0.66` (ersetzt `scale` in der Wallpaper-URL).
- Subkey pro Monitor `Software\KuroScreensaver\Monitors\<Id>`:
  `Mode` (`on|off|random|scene`, Default `on`), `Scene` (Slug), `Preset` (Slug oder leer),
  `WMode` (`on|off|random|scene`, Default: Primär `on`, sonst `off`), `WScene`, `WPreset`.
- Monitor-Id: sanitized aus `DISPLAYCONFIG_TARGET_DEVICE_NAME.monitorDevicePath`
  (nur `[A-Za-z0-9_-]`, andere Zeichen → `_`, max 128); Fallback `GetMonitorInfoW.szDevice`
  gleich sanitized.

### Save-Message v0.10

`save:<voller 33-Key-Query ohne '?'>` + optional angehängte Monitor-Keys
(`&m0id=…&m0mode=…&m0scene=…&m0preset=…&m1id=…`, Index 0..7 lückenlos;
`mNscene`/`mNpreset` dürfen leer sein). `cancel` unverändert. NEU Host→Seite:
`saveerror` (Save abgelehnt, Dialog bleibt offen) via `PostWebMessageAsString`.
Saver-URLs bekommen zusätzlich konstant `&kiosk=on` (KEIN Registry-Wert).
Wallpaper-URLs: `&kiosk=on&audio=off` erzwungen + `scale=<WallpaperScale>` statt `Scale`.

### Host→Page Power-Messages (nur Wallpaper)

`power:hidden` | `power:frozen` | `power:animating:<fps>` als WebMessage-String.

function readNum(params: URLSearchParams, key: string, lo: number, hi: number): number | undefined {
  const raw = params.get(key);
  if (raw === null || !/^[0-9]+(\.[0-9]+)?$/.test(raw)) return undefined;
  const v = parseFloat(raw);
  return Math.min(hi, Math.max(lo, v));
}
function readEnum<T extends string>(params: URLSearchParams, key: string, allowed: readonly T[]): T | undefined {
  const v = params.get(key);

}
